🧭 排期思路（为什么这么排）

① 三天三条主线：山 → 水 → 城，各占一天

D1 山（悬空寺）：最户外、最怕雨的景点放在到达日趁小雨拿下——因为后面雨更大；D2 水（千岛湖）：雨最大的一天选"船上有棚"的项目，烟雨湖景本身是千岛湖的招牌气质，体验不亏；D3 城（严州古城）：晴天收尾，古城离建德站只有 20 分钟，赶车零风险。三天主题不重复、互不抢时间。

② D1 悬空寺：为什么"先山后酒店"，不能"先酒店后山"
  • 关键时间窗：大慈岩 16:00 关门、索道约 15:00 停运。
  • 先酒店后山（否决）：12:10 建德南 → 50 分钟到酒店（13:05）→ 放行李+午餐 → 14:00 出发 → 15:10 才到山 → 只剩不到 1 小时，玩不完。不成立。
  • 先山后酒店（采纳）：建德南 → 大慈岩仅 21.7km / 35 分钟（顺路），行李寄存游客中心，13:15 前上索道，15:30 前玩完，16:00 取行李，17:20 到酒店。顺路 + 时间够 + 行李无负担。
③ D2 千岛湖 vs 卧龙胜境漂流（本次改版核心）
维度千岛湖（主）卧龙胜境漂流（降备选）
位置淳安，梅城过去 62km / 1h40寿昌镇，与大慈岩/悬空寺同方向，D1 已跑过那片
雨天适配游船有棚，中雨照常（仅大风大雾停航）窗口 14:00–15:00，中雨可能临时停运
耗时全天 5–7h，玩得满1.5–2h，窗口苛刻、迟到作废
路线重复无与 D1 方向重复，来回跑两趟同片区

结论：漂流是"地点重复 + 时间窗口苛刻 + 雨天不确定"三不利；千岛湖是"雨也成立 + 内容饱满 + 主题契合（D2 就是水）"。故千岛湖升主方案，漂流降为备选。

④ D2 备选阶梯排序逻辑（按"省事程度 × 雨天友好度"）
  1. 七里扬帆游船：就在酒店旁姚坞码头，0 赶路，船有棚，雨天照开；
  2. 灵栖洞 + 新安江城区组合线：两处都在市区及以南方向，顺路串一条，且全部"不怕雨"（溶洞、室内水电站、雨中江雾）；
  3. 卧龙胜境漂流：重复路线 + 窗口苛刻 + 停运风险，放最后兜底。
⑤ D3 硬约束推理

硬约束：16:31 建德站发车 → 16:00 前进站 → 15:30 从酒店出发 → 任何上午加项必须在 14:00 前回到酒店。因此 D3 原则是近 > 特色：古城补完最稳；加分项三选一（七里扬帆 / 新叶 / 八卦村），不贪多。

D2 · 10/4（周日）· 小雨转中雨 17~24℃ · 千岛湖日（主方案）

为什么选千岛湖（推理）

10/4 是三天降雨最大的一天（约 13mm）。千岛湖游船有棚、仅大风/大雾停航，中雨也成立；全天 5–7 小时刚好把一天填满，是本次行程的招牌体验。代价 = 早起（7:00 出发）+ 往返 3 小时 20 分车程，这一天就当"在路上看湖景"。

时间线

07:00梅城出发 → 千岛湖中心湖区（62km / 1h40 / 约 220 元）

必须 7 点走：千岛湖 13:30 后无全天环线，晚出发只能玩半天。

08:40到中心湖区旅游码头（梦姑路 348 号）买票优先 9:00–9:30 班
09:00-15:30游船登岛（散客公交船约 185 元 = 门票 130 + 船票；定时班次 8:30 / 9:00 / 9:30 / 10:00，滚动发船）

1 号线：梅峰岛（缆车 60 元可选，俯瞰 300 余岛全景，必去）→ 渔乐岛（餐饮娱乐）→ 龙山岛（海瑞祠等人文）→ 月光岛（4 岛 3 桥，最出片），全程 5–7 小时。

豪华船备选：梦想号 / 伯爵号约 4 小时，只打梅峰 + 月光两精华岛、上午班含自助餐，价格更高、更省时。

15:30-16:00下船，码头周边或返程路上解决晚餐（千岛湖鱼头）
17:40回到梅城酒店
晚上古城夜景 / 三江口散步（若还有精力）

千岛湖玩法要点（详细）

  • 码头：中心湖区旅游码头（淳安县千岛湖镇梦姑路 348 号）。
  • 票价：散客公交船约 185 元（门票 130 + 船票）；梅峰缆车 60 元（可选）。
  • 班次：8:00–13:00 滚动发船；定时班次 8:30 / 9:00 / 9:30 / 10:00；13:30 后无全天环线。
  • 航线（公交船 1 号线）：梅峰岛（俯瞰 300 余岛全景，缆车或徒步约 20 分钟登顶）→ 渔乐岛（餐饮娱乐）→ 龙山岛（海瑞祠等人文）→ 月光岛（4 岛 3 桥，最出片）。
  • 豪华船备选：梦想号 / 伯爵号约 4 小时，只打梅峰 + 月光两精华岛、上午班含自助餐，价格更高、更省时。
  • 注意事项：① 记好各岛返程集合时间，错过要等下一班；② 岛上餐饮贵，可自带零食；③ 雨天登岛带伞、穿防滑鞋；④ 船上风大，带薄外套；⑤ 若 10/4 早上下暴雨（大到暴雨），临时改走七里扬帆游船（见备选 1）。

🔁 D2 备选方案（按推荐顺序）

备选 1 · 七里扬帆游船（最省事：就在酒店旁）

位置：姚坞码头（梅城镇严东关路），距酒店 5–10 分钟车程。

内容：富春江小三峡游船（《富春山居图》实景段），航程约 2.5–4 小时，可停靠葫芦瀑布观景。注意：葫芦峡漂流 9/1 起已停漂，但游船观光照常开放。

票价：官方 130 元（门票 80 + 船票 50），平台 90–120 元不等。

班次：非周末 10:30、13:00；周末 9:00、10:30、13:00。

提醒：船有棚、雨天照常；散客建议提前 1 天电话确认拼船（官方有时以团队为主）。适用：不想跑远、想省力、天气差的时候。

备选 2 · 灵栖洞 + 新安江城区组合线（雨天深度线，已合并）

合并逻辑：两处都在建德市区及以南方向，顺路一条线串完；且都"不怕雨"——灵栖洞是溶洞（恒温 17℃），新安江水电站以室内参观为主，江滨公园雨中江雾反而更仙。是 10/4 雨天内容最充实的一条线。

组合路线（推荐执行版）

  • 08:30 梅城出发 → 09:15 到灵栖洞（约 59km / 1h / 约 200 元）
  • 09:30–11:45 灵栖洞三洞全程（2–2.5h）
  • 12:15 到新安江城区午餐（白沙桥头吃鱼，约 30km / 40min）
  • 13:30–15:30 新安江水电站（室内为主）
  • 15:45–17:00 江滨公园 / 水杉林水上森林散步（免费，雨中江雾出片）
  • 18:30 双江街码头 → 19:00 江清月近人实景演艺（可选，雨天是否开演提前问）→ 22:00 前回梅城

省力精简版：上午水电站 + 江滨 → 下午灵栖洞 → 傍晚回（砍掉夜游）。

灵栖洞详情

4A 溶洞群、86 版《西游记》取景地；灵泉洞乘船游地下暗河 → 清风洞 → 飞天魔毯 → 霭云洞（雨后常有云雾）→ 滑道下山 → 石林；线上 75 / 现场 80 元（含三洞 + 游船）；8:00–16:00 停止入园；全程 2–3h；洞内恒温 17℃，带薄外套、防滑鞋。

新安江水电站详情

中国第一座自行设计建造的大型水电站；38 元 / +展览馆联票 55–58 元；8:00–16:00；展览馆周二闭馆（10/4 是周日，正常开）；参观 1.5–2h；票务 0571-64542543；停车免费。

城区往返：梅城 → 城区 27km / 45min / 约 90 元。

备选 3 · 卧龙胜境漂流（已降级，兜底）

位置：寿昌镇金桥村里诸自然村；国庆 10/1–10/7 每天 14:00–15:00 开漂（约 4.3km：1km 玻璃滑道 + 3.3km 峡谷漂流，全湿）；电话 0571-58306588。

降级原因：与 D1 悬空寺同处大慈岩 / 寿昌方向，路线重复；窗口仅 1 小时、迟到作废；10/4 中雨天可能临时停运。

启用条件：10/4 天气意外转晴且你想玩水 → 13:00 出发 → 14:00–15:00 漂 → 17:00 回。

装备：速干衣 / 泳衣、整套换洗、手机防水袋、拖鞋。
